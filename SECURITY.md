# Sécurité

Une faille dans Fifty ? Ne l'ouvre pas en issue publique.

Utilise « Report a vulnerability » dans l'onglet Security du dépôt (signalement privé), ou écris à matheo.gunay@gmail.com. Je réponds en quelques jours.

Ne publie jamais de pseudo, de clé ou d'URL de base de données dans un signalement public.
