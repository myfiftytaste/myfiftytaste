# Display Profile Contract

This document describes `data/output/{username}_display_profile.json`, the UI-facing profile payload for MyFiftyTaste.

The payload is generated by `scripts/build_display_profile.py` from:

- `data/output/{username}_wrapped.json`
- `data/output/{username}_profile_metrics.json`
- `data/config/display_config.json`

Visible text such as card titles, labels, descriptions, archetype names, subtitles, one-liners, warning copy, and display order should be configured in `data/config/display_config.json`, not hardcoded in calculation scripts.

## Root

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| `user` | string | `"tanguytare"` | Stable username for routing, page titles, and analytics. |
| `source_files` | object | `{ "wrapped": "...", "profile_metrics": "...", "display_config": "..." }` | Debug/audit provenance; not required for public UI. |
| `hero` | object | See below | Primary profile header content. |
| `cards` | array of objects | See below | Ordered list of metric cards to render. |
| `highlights` | object | See below | Featured films/director for visual modules. |
| `warnings` | array of strings | `["Social stats are based only..."]` | User-facing caveats or small print. |
| `config_fallback_warnings` | array of strings | `[]` | Build/audit warnings when config keys are missing; useful for QA, not public UI. |

## `hero`

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| `username` | string | `"tanguytare"` | Displayed profile owner. |
| `primary_archetype_id` | string | `"demanding_explorer"` | Stable technical ID for styling, themes, icons, and experiments. |
| `primary_archetype` | string | `"The Demanding Explorer"` | Visible archetype name from `display_config.json`. |
| `subtitle` | string | `"Exacting taste, wide horizons."` | Secondary hero headline. |
| `one_liner` | string | `"You wander far..."` | Short explanatory copy for the hero. |
| `social_coverage` | number | `0.7` | Coverage badge/progress value for social stats. |
| `metadata_coverage` | number | `0.96` | Coverage badge/progress value for confirmed metadata. |

## `cards`

`cards` is an ordered array. Card order comes from `display_config.json`.

Each card must contain:

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| `id` | string | `"rating_personality"` | Stable technical ID for rendering logic and tracking. |
| `title` | string | `"Rating personality"` | Visible card title from config. |
| `value` | string or null | `"-0.52"` | Main card value. |
| `label` | string | `"Severe"` | Compact interpretation or score name from config/template. |
| `description` | string | `"You rate about 0.52 stars lower..."` | Body copy from config/template. |
| `confidence` | string | `"high"` | UI confidence chip. Expected values: `high`, `medium`, `low`. |
| `data_source` | string | `"35 films with Megabank social stats"` | Small source note under the card. |

Expected card IDs:

- `rating_personality`
- `niche_profile`
- `cult_profile`
- `runtime_profile`
- `genre_dna`
- `country_passport`
- `director_recurrence`

## `highlights`

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| `most_niche` | film object or null | `{ "title": "L'Argent", "slug": "largent-1983" }` | Highlight tile for least-watched social film. |
| `most_mainstream` | film object or null | `{ "title": "The Menu", "slug": "the-menu-2022" }` | Highlight tile for most-watched social film. |
| `most_cult` | film object or null | `{ "title": "Cinema Paradiso", "slug": "cinema-paradiso" }` | Highlight tile for highest fans/watches ratio. |
| `longest` | film object or null | `{ "title": "The Godfather Part II", "slug": "the-godfather-part-ii" }` | Runtime highlight. |
| `shortest` | film object or null | `{ "title": "Obsession", "slug": "obsession-2025" }` | Runtime highlight. |
| `most_repeated_director` | object or null | `{ "director": "Brian De Palma", "count": 3 }` | Director recurrence highlight. |

Film highlight object:

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| `title` | string or null | `"L'Argent"` | Visible film title. |
| `rss_title` | string or null | `"L'Argent, 1983 - ★★½"` | Original RSS title, useful for audit or fallback display. |
| `slug` | string or null | `"largent-1983"` | Letterboxd slug for links and keys. |
| `url` | string or null | `"https://letterboxd.com/.../film/largent-1983/"` | Outbound Letterboxd link. |
| `source` | string or null | `"megabank"` | Provenance badge or debug display. |

## `warnings`

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| item | string | `"Some films are waiting for manual metadata validation."` | User-facing caveat. Copy comes from `display_config.json`. |

## `config_fallback_warnings`

| Field | Type | Example | Frontend role |
| --- | --- | --- | --- |
| item | string | `"Missing display_config key: cards.niche_profile.title"` | QA/build diagnostic. Shows that a visible text fallback was used. |

The public frontend may hide this field, but validation should keep it available during development.
